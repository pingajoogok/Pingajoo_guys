# **Pingajoo** 🚀

A powerful Chrome extension for students taking tests on **Examly/Iamneo**, **NPTEL**, and other exam portals.

> [!WARNING]
> **Educational Purposes Only**: This extension is intended for educational purposes. Please use it responsibly and ethically.
> We are not responsible for any actions taken, and we do not encourage or promote cheating in any way.

## ✨ Features

- **`Examly Bypass`** — Break free from Examly's limitations. Pingajoo bypasses the NeoExamShield extension
- **`Tab Switch Bypass`** — Prevents unwanted tab switch restrictions (report shows 0 switches)
- **`NPTEL Integration`** — Solve NPTEL Wildlife Ecology, Conservation Geography, and Forest Management answers
- **`AI Search Answers/Code`** — Perform AI-powered searches without switching tabs
- **`Chatbot With Stealth Mode`** — Leverage AI Chatbot to enhance your search capabilities
- **`Solve MCQ`** — Quickly search MCQ answers by simply selecting text
- **`Pasting When Restricted`** — Paste answers with ease using drag and drop
- **`Custom AI API`** — Use your own API key (OpenAI, Anthropic, Google, DeepSeek, or custom)

## ⬇️ Installation

1. [Download] the extension
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode** in the top right corner
4. Click **Load unpacked** and select the Pingajoo folder
5. You're all set — login required in the extension! ✅

## 💻 Usage

Once installed, the extension is **automatically active** — no login needed. Open the popup to see available shortcuts and configure options.

## ⌨️ Shortcuts

### Examly / Iamneo

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + Q` | Answer Neo Questions with 100% Accuracy |
| `Ctrl + Shift + T` | Type Neo Coding Answers |
| `Alt + Shift + A` | Search Neo Answers Using AI |

### Universal

| Shortcut | Action |
|---|---|
| `Alt + Shift + S` | Search Answers Using AI *(select text first)* |
| `Alt + Shift + M` | Solve MCQs Using AI *(select text first)* |
| `Alt + C` | Toggle Chatbot Overlay |
| `Alt + Shift + V` | Paste Using Drag and Drop |

### HackerRank

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + H` | Solve HackerRank Questions [BETA] |

### NPTEL

| Shortcut | Action |
|---|---|
| `Alt + Shift + N` | Solve NPTEL MCQs *(select text first)* |

> [!NOTE]
> On **Mac**, replace `Alt` with `Option` and `Ctrl` with `Cmd`.

## 🤝 Contribute NPTEL Dataset

1. Fork this repository
2. Open your NPTEL assignment page in the browser
3. Open developer tools (`F12`)
4. Go to the Console tab
5. Paste and run the script from `nptel.txt`
6. Copy the output JSON data
7. Update `data/nptel.json` with the new questions
8. Create a pull request
